# Twitch Live Alerts

An Android app that monitors Twitch channels you follow and posts go-live notifications.

## Quick start

Build the debug APK:

```sh
just build
```

The APK is written to `app/build/outputs/apk/debug/Twitch Live Alerts - 1.0.2 - DEBUG.apk`. See [Setup](SETUP.md) to install and configure it, and [Development](DEVELOPMENT.md) for build requirements and other commands.
